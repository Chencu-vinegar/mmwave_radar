# 更新日志 (Changelog)

本文档记录本项目的版本更新。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。

## [v0.1] - 2026-11-05

初版数据读取与收集软件，围绕矽典微 DEV202H（ICL1122）毫米波雷达实现从原始字节流到可视化、导出的完整链路。

### 新增

#### 数据读取
- 离线解析：读取 SDK 保存的 `.dat` 数据文件，自动识别同目录下的 `FILE_Radar_Config.ini`，也支持手动指定配置文件
- 串口实时：通过 USB 串口实时读取（默认 921600 波特率），边接收边增量解析
- 原始数据录制：实时数据流可录制为 `.dat` 文件，供后续离线回放

#### 数据解析
- 解析 `ICLH` 帧协议：52 字节数据帧 + 16 字节短帧，大端 int16 复采样 I/Q
- 组帧对齐：counter 每 chirp 递增 16、每 64 chirp 回绕为 1 个雷达帧，同 counter 的 RX0/RX1 配对成完整 chirp
- 相位法角度估计（1T2R）：`θ = arcsin(Δφ / (2π·d_ant/λ))`，`Δφ = angle(RX1·conj(RX0))`

#### 可视化
- BEV 俯视热图
- 距离-角度图
- 距离-时间图
- 最新单帧散点图
- 3D 点云
- 热图对比度自适应（对数归一化 + 掩膜），解决原始热图整体过暗/过亮、目标不可辨的问题

#### 导出
- 点云导出 CSV
- 热图导出 PNG + 同名 CSV 数值矩阵
- 录制原始 `.dat`

#### 交互
- 指定帧回放
- 距离范围缩放
- 镜像切换

### 已知限制

- 数据格式为对 DEV202H 设备输出逆向所得，不保证与官方协议完全一致
- 实时模式在部分设备/串口环境下仍在验证中，可能出现无图像的情况
- 界面与接口尚未稳定，后续版本可能调整
