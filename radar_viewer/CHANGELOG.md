# 更新日志 (Changelog)

本文档记录本项目的版本更新。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。

## [v0.3] - 2026-11-05

优化串口实时显示的帧率与准确性，便于后端连接后实时反应。

### 优化

- **实时刷新率 10 → 约 30 FPS**：刷新循环由固定 `after(100)`（10 FPS）改为目标间隔 33 ms，并按每轮实际渲染耗时自适应调度（`max(5, LIVE_REFRESH_MS - cost)`），避免事件堆积；未连接时低频轮询（200 ms）以降低空闲 CPU 占用
- **blit 增量重绘**：实时图从每帧 `draw_idle()` 全量重绘改为 blit 只重绘 4 个动态 artist（BEV / 距离-角度 / 距离-时间 imshow + 最新帧散点），渲染开销大幅下降；窗口尺寸变化或工具栏缩放/平移后自动失效并重新捕获背景，异常时回退全量重绘
- **snapshot 减负**：`SerialRadarReader.snapshot(n)` 支持只取最近 n 个 chirp；实时刷新只复制最近 `RT_WINDOW + 1` 帧（约 3264 chirp），而非整个 19200 chirp 滚动缓冲，降低复制与后续数组构建开销

### 改进（准确性）

- **瞬时帧率显示**：FPS 由「累计平均」（`总帧数/总时长`）改为「EMA 平滑瞬时帧率」，更准确反映实时刷新而非随时间趋于稳定后的失真值
- **热图颜色映射稳定**：BEV / 距离-角度 / 距离-时间热图的 `clim`（对数颜色上下限）加入 EMA 平滑，避免因只用最近 6 帧算分位数而导致的逐帧颜色剧烈抖动
- **最新帧号展示**：最新帧号改到状态栏显示（标题保持静态，配合 blit 增量重绘）

### 验证

- `py_compile` 通过；`radar_app` 可正常导入；`snapshot(n)` 回归测试通过（69 chirp / 2 帧 / 0 错误，尾部截取与全量导出行为正确）

## [v0.1.1] - 2026-11-05

修复串口实时「无图像」问题。

### 修复

- **串口实时无图像**：真实串口直读的字节流并非 `.dat` 文件的 `ICLH` 封装，而是 `55 AA` 同步头的 40 字节裸帧（原 `serial_live.py` 只认 `ICLH` 头，导致一帧都解析不出来）。
  - 帧格式：`55 AA | ch(1B) | cnt_lo(1B) | cnt_hi(1B) | 8×复数(32B, 大端 int16 I/Q) | 尾(3B)`
  - `ch`：bit7 = RX 通道（0=RX0 / 1=RX1），bit0-3 = chirp 序号高 2 位，bit4-5 = `0x30` 固定
  - 完整 chirp 序号 = `(ch & 0x0F) * 16 + (cnt_lo >> 4)`，范围 0~63（= 64 chirp/帧），counter 每 chirp +16
  - 新增帧头严格校验（`ch & 0x70 == 0x30` 且 `cnt_hi == 0x09`），避免把数据区里偶然出现的 `55 AA` 误判为帧头
- 修复后 `serial_live.py` 将 `55 AA` 裸帧翻译为与 ICLH 一致的 `(counter, channel, 复数)`，下游 chirp 配对与可视化逻辑无需改动；`.dat` 文件解析（`radar_parser.py`）保持 ICLH 解析不变

### 验证

- 真机采样回放：约 3 秒 118 KB 字节流解析出 1479 chirp / 25 帧 / 0 错误；实时连接 5 秒累计 2472 chirp / 40 帧 / 0 错误，RX0/RX1 幅度与相位差正常
- 分块回放（13 字节/块）与整块回放结果一致，帧边界处理正确

### 部署

- 重新打包 `mmwave-radar.exe`（PyInstaller onefile），旧程序已备份为 `mmwave-radar.exe.bak`

## [v0.1] - 2026-11-05

初版数据读取与收集软件，围绕矽典微 DEV202H（ICL1122）毫米波雷达实现从原始字节流到可视化、导出的完整链路。

### 新增

#### 数据读取
- 离线解析：读取 SDK 保存的 `.dat` 数据文件，自动识别同目录下的 `FILE_Radar_Config.ini`，也支持手动指定配置文件
- 串口实时：通过 USB 串口实时读取（默认 921600 波特率），边接收边增量解析
- 原始数据录制：实时数据流可录制为 `.dat` 文件，供后续离线回放

#### 数据解析
- 解析 `ICLH` 帧协议：52 字节数据帧 + 16 字节短帧，大端 int16 复采样 I/Q
- 组帧对齐：counter 每 chirp 递增 16、每 64 chirp 回绕为 1 个雷达帧，同 counter 的 RX0/RX1 配对成完整 chirp
- 相位法角度估计（1T2R）：`θ = arcsin(Δφ / (2π·d_ant/λ))`，`Δφ = angle(RX1·conj(RX0))`

#### 可视化
- BEV 俯视热图
- 距离-角度图
- 距离-时间图
- 最新单帧散点图
- 3D 点云
- 热图对比度自适应（对数归一化 + 掩膜），解决原始热图整体过暗/过亮、目标不可辨的问题

#### 导出
- 点云导出 CSV
- 热图导出 PNG + 同名 CSV 数值矩阵
- 录制原始 `.dat`

#### 交互
- 指定帧回放
- 距离范围缩放
- 镜像切换

### 已知限制

- 数据格式为对 DEV202H 设备输出逆向所得，不保证与官方协议完全一致
- 实时模式在部分设备/串口环境下仍在验证中，可能出现无图像的情况
- 界面与接口尚未稳定，后续版本可能调整
