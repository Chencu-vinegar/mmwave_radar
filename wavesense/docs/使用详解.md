# WaveSense 使用详解

这份文档面向第一次接触本项目的同学，从安装到每一个页面元素都讲清楚。照着做即可，不需要有编程基础。

---

## 一、这是什么

WaveSense 用一个 24GHz 毫米波雷达（矽典微 DEV202）判断房间里**有没有人、在做什么动作**，并把结果显示出来、记录下来。整个过程**全本地运行，不联网、不接云、不需要账号、不用训练模型**。

它有两种使用形态：

- **本地网页（推荐）**：浏览器打开一个页面，能看到大字状态、实时曲线和事件记录，电脑、手机都能看。
- **终端文字**：直接在命令行看状态文字，适合调试。

数据有三种来源：

| 来源 | 参数 | 是否需要硬件 | 用途 |
|---|---|---|---|
| 实时串口 | `--source serial` | 需要雷达 | 接真实雷达，现场实时演示 |
| 回放 | `--source replay` | 不需要 | 播放之前录制的 `.gz` 文件 |
| 合成 | `--source simulated` | 不需要 | 程序自己造数据，无硬件时先看效果 |

## 二、准备工作（只做一次）

### 2.1 安装 Python

1. 到 https://www.python.org/downloads/ 下载 **Python 3.10 或更高版本**。
2. Windows 安装时**务必勾选 "Add Python to PATH"**，再点安装。
3. 安装后验证：打开终端，输入 `python3 --version`（Windows 用 `python --version`），能看到版本号即可。

### 2.2 在项目文件夹里打开终端

把项目文件夹（如 `夜间程序` 或解压后的 `wavesense`）放到本地，在**这个文件夹的根目录**打开终端：

- macOS：在文件夹上右键 → "服务 → 新建位于文件夹位置的终端窗口"；
- Windows：进入文件夹，在地址栏输入 `powershell` 回车。

### 2.3 创建虚拟环境并安装依赖

**macOS：**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**Windows（PowerShell）：**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

> 如果 PowerShell 禁止运行激活脚本，改用：
> `.venv\Scripts\python.exe -m pip install -r requirements.txt`

依赖只有 4 个：`numpy`（数值计算）、`pyserial`（读串口）、`paho-mqtt`（消息发布）、`PyYAML`（读配置），安装很快。

### 2.4 接硬件（只用真实雷达时需要）

参照 `docs/硬件连接方式.jpg`，用 4 根杜邦线连接：

```
DEV202 雷达（黄色小板）
   红 = VCC 电源
   黑 = GND 地
   白 / 黄 = TXD / RXD 数据
        ↓
USB 转 TTL 串口模组（蓝色小板）→ 插入电脑 USB
```

如果系统不认串口：

- Windows 一般自动识别；
- macOS 若没有新设备，安装 CH340（WCH）驱动：https://www.wch.cn/downloads/CH34XSER_MAC_ZIP.html

## 三、本地网页用法（重点）

### 3.1 启动

在普通命令前加 `--web` 即可。启动命令只决定**最初加载**的数据源；进入页面后仍可在顶部「实时输入 / 数据导入」之间切换，不必重启程序。三种初始数据来源分别是：

```bash
# 1) 无硬件，先看内置演示剧情（合成数据，最适合第一次尝试）
PYTHONPATH=. python3 -m src.main --web --source simulated --scenario demo

# 2) 回放一个录制文件
PYTHONPATH=. python3 -m src.main --web --source replay --file /path/文件.gz

# 3) 接真实雷达，实时演示
PYTHONPATH=. python3 -m src.main --web --source serial
```

> Windows PowerShell：把 `python3` 换成 `python`，把开头的 `PYTHONPATH=.` 换成单独一行 `$env:PYTHONPATH="."`。

启动成功后，终端会打印类似：

```
网页已启动：http://localhost:8080 （Ctrl+C 退出）
```

### 3.2 打开页面

- **电脑**：浏览器直接访问 `http://localhost:8080`。
- **手机**：手机和电脑连同一个 Wi-Fi，用电脑的**局域网 IP** 访问，例如 `http://192.168.1.23:8080`。
  - macOS 查 IP：系统设置 → Wi-Fi → 详细信息；
  - Windows 查 IP：终端运行 `ipconfig`，看 IPv4 地址。
- 按 **Ctrl+C** 停止服务。

### 3.3 页面各部分详解

页面从上到下依次是：模式切换与控制面板、数据分析报告、在场状态、动作分级、能量曲线、事件记录、操作按钮。

**① 顶部信息栏**

显示标题、运行时长、已处理帧数、事件数，以及当前运行模式（“实时采集：串口名”或“文件回放：文件名”）和数据源名称。回放/合成数据播完后，右侧会出现“回放已结束”标记。

**② 模式切换与控制面板（双模式）**

顶部两个大按钮在「实时输入」和「数据导入」之间切换控制面板（绿色高亮为当前查看项；顶部信息栏始终显示后端实际正在运行的模式，二者不必相同）。

- **实时输入（毫米波雷达串口）面板**：
  - 下拉框列出当前可用串口，点“刷新串口”重新扫描；
  - 点“连接并开始”按所选串口接入真实雷达，开始实时采集并即时刷新有人/动作/曲线；
  - 未接硬件、扫描不到串口时会用红字提示“没有可用串口”，此时仍可查看回放与历史报告。
- **数据导入（.gz / .dat 录制文件）面板**：
  - 点“选择文件”挑选本地录制，支持 `.gz`（授权软件 gzip 导出）和 `.dat`（原始二进制录制），其他类型会被拒绝；
  - 选好后点“上传并分析”，文件上传到后端并自动限速回放；
  - 回放过程体现在状态、曲线和事件流里；播完后自动生成下方分析报告。

**③ 数据分析报告（文件回放结束后出现）**

整段文件跑完后自动汇总，字段含义：

| 字段 | 含义 |
|---|---|
| 数据文件 | 本次回放的文件名 |
| 总帧数 / 时长(秒) | 逻辑帧总数；按约 480fps 换算的时长 |
| 有人占比(%) | 整段中判定“有人”的帧比例 |
| 不动 / 小动 / 大动 | 有人帧中三级动作的占比条 |
| 进入次数 / 离开次数 | 在场状态翻转次数 |
| 最终状态 / 结束时间 | 片段末尾是否有人、结束墙钟时间 |

实时采集不会结束，因此不显示该报告卡片。

**④ 在场状态卡片**

- 绿色大字 **"有人"** + 绿色圆点：雷达判断房间里有人；
- 灰色大字 **"无人"** + 灰色圆点：判断房间无人；
- 旁边显示当前本地时间。

**⑤ 动作分级卡片**

用一个彩色标签表示当前动作，分三级：

| 标签 | 含义 |
|---|---|
| 不动（灰色） | 人在但基本静止，例如静坐、呼吸 |
| 小动（琥珀色） | 小幅动作，例如挥手、转头、调整姿势 |
| 大动（橙色） | 明显动作，例如走动、起身 |

下方还显示当前的动作门、距离门能量数值。

**⑥ 实时能量曲线**

- 蓝线：**距离门短窗能量**，反映有没有人；
- 橙线：**动作门短窗能量**，反映动作大小；
- 浅色背景带：该时段处于"有人"状态；
- 纵轴按当前窗口的最大值自动缩放，左上角显示当前最大值；
- 显示最近约 5 秒的数据，随时间向左滚动。

**⑦ 事件记录**

自动记录三类事件，每条带时间、帧号和当时动作：

- **进入**：状态从无人变为有人；
- **离开**：状态从有人变为无人；
- **动作·xxx**：有人时动作分级发生变化。

**⑧ 两个按钮**

- **导出 CSV**：把全部事件存成一个 CSV 文件（带中文表头和 UTF-8 BOM，Excel 双击不乱码），文件名 `wavesense_events.csv`；
- **清空记录**：清空当前事件列表。

事件会持久化到 `web_data/events.json`，**关闭程序再打开不会丢**；点清空后才会清除。

### 3.4 常用地址参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--http-port` | 8080 | 网页端口，被占用时换一个，如 `--http-port 9000` |
| `--host` | 0.0.0.0 | 监听地址，默认允许局域网访问；只本机能访问可设 `127.0.0.1` |

## 四、终端文字模式（不用网页）

不加 `--web` 时，直接在终端看文字。

```bash
# 实时串口：底部每 0.25 秒刷新一行，状态翻转/动作变化会换行打印
PYTHONPATH=. python3 -m src.main --source serial

# 回放：只在有人/无人翻转时打印一行
PYTHONPATH=. python3 -m src.main --source replay --file /path/文件.gz

# 合成：指定场景，可选 demo / empty / sit / small / large
PYTHONPATH=. python3 -m src.main --source simulated --scenario demo
```

实时状态行示例：

```
状态：有人　不动　短窗动作区 1.30e+08　帧 1234
```

加 `--mqtt` 可同时把结果发布到 MQTT（用于 Home Assistant，需要先起 broker）。

## 六、文件结构说明

```
项目根目录/
  config/config.yaml        # 全部阈值、窗口、MQTT 参数（真实标定值）
  requirements.txt          # 依赖清单
  src/
    config.py               # 读取 config.yaml
    data_source/            # 三种数据来源 + 二进制帧解析
      frame.py              # 统一帧结构
      file_replay.py        # 回放 .gz/.dat
      serial_source.py      # 实时串口
      simulated.py          # 合成数据
      stream_parser.py      # 流式解析（粘包/分包）
    detector/detector.py    # 判定状态机 + 动作分级
    mqtt_publisher.py       # MQTT 发布
    web/                    # 本地网页（双模式）
      engine.py             # 后台采集引擎：运行时切换数据源 + 整段分析统计
      server.py             # HTTP 服务器：状态/事件/CSV/串口/实时切换/上传接口
      static/index.html     # 前端页面（实时输入 / 数据导入 + 分析报告）
    main.py                 # 程序入口
  web_data/events.json      # 网页事件持久化（页面可清空）
  web_data/uploads/         # 页面“数据导入”上传的 .gz/.dat
  samples/                  # 原始录制文件
  dataset/                  # 切分后的纯数据集
  deploy/                   # Home Assistant / Mosquitto 部署配置
  tools/                    # 各种分析、切分、测试脚本
  tests/                    # 单元测试
  docs/                     # 文档与接线图
```

## 七、常见问题

**1. 没找到串口 / 串口列表为空**
确认 USB 转串口模组插好、需要的驱动已安装（见 2.4）。

**2. 数据乱码或读不到数据**
通常是波特率问题，从高到低依次尝试 `--baud 921600`、`460800`、`230400`、`115200`。

**3. 空房间却一直判"有人"**
检查雷达视野内有没有持续运动或振动的设备：饮水机、风扇、空调、电脑风扇、晃动的窗帘。程序能过滤近门电器的慢速振动，但电器压缩机/水泵**启动瞬间**（约 0.3 秒）信号和人手一样强，会短暂判有人。演示前最好关闭空调、饮水机。

**4. 开机时人已经坐着，没识别出来**
做一个挥手或起身动作即可，识别后静坐会一直保持。

**5. 串口连上了但一直不刷新**
说明没收到雷达数据，检查雷达供电（红线 VCC）和接线是否牢固，或按 Ctrl+C 重连。

**6. 启动报端口被占用（Address already in use）**
用 `--http-port 9000` 换一个端口，访问时把网址端口一起换掉。

**7. 手机打不开页面**
确认手机和电脑连同一个 Wi-Fi；确认用的是电脑局域网 IP 而非 localhost；检查电脑防火墙是否放行。

**8. PowerShell 出现红色文字**
不一定是错误。pip 升级提示、测试进度等写在 stderr 会显示成红色，只要最后看到 `OK`、`全部通过` 或正常状态行即可忽略。

**9. 数据导入支持什么格式、为什么上传被拒**
只接受 `.gz`（授权软件 gzip 导出的录制）和 `.dat`（原始二进制录制）；CSV、TXT、图片等其他类型会被拒绝并红字提示。上传后自动限速回放，播完才出现完整“数据分析报告”；实时采集不会结束，因此不生成报告。

## 八、当前已知的功能边界

本项目定位为**单房间存在/运动检测**，以下功能做了简化，答辩时可如实说明：

- **人数计数**：只输出"有人/无人"（0/1），不区分房间里具体有几个人；多人计数列为后续工作。
- **位置坐标**：只有 6 个距离门的能量，不输出具体坐标或位置散点。
- **灯控**：Home Assistant 中的灯目前是占位实体，现场需替换为真实智能灯。
