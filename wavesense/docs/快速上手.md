# WaveSense 快速上手（给同学）

连接板子后，用电脑实时判断房间里**有没有人、在做什么动作**。全程不联网、不需要云。

---

## 1. 准备（只做一次）

### 1.1 装 Python

- 到官网 https://www.python.org/downloads/ 下载并安装 **Python 3.10 或更高版本**。
- **Windows 安装时务必勾选 "Add Python to PATH"**。

### 1.2 接线

参照 `docs/硬件连接方式.jpg`：

```
DEV202 雷达（黄色小板）
   └─ 4 根杜邦线 ── USB 转 TTL 串口模组（蓝色小板）
        红 = VCC 电源
        黑 = GND 地
        白 / 黄 = TXD / RXD 数据
   └─ USB 口插电脑
```

插上后，如果系统不认串口：

- Windows 10/11 一般会自动识别；
- macOS 若没出现新设备，需安装 CH340（WCH）串口驱动：https://www.wch.cn/downloads/CH34XSER_MAC_ZIP.html

---

## 2. 运行程序

把项目压缩包解压，在解压出的 **`WaveSense` 文件夹**中打开终端。

### macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

PYTHONPATH=. python -m src.main --source serial
```

### Windows（PowerShell）

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt

$env:PYTHONPATH="."
python -m src.main --source serial
```

> 如果 PowerShell 提示无法运行激活脚本，可改用：
>
> ```powershell
> .venv\Scripts\python.exe -m pip install -r requirements.txt
> $env:PYTHONPATH="."
> .venv\Scripts\python.exe -m src.main --source serial
> ```

程序会自动列出串口并选择；若有多个，可用 `--port` 指定，例如：

```bash
# macOS
PYTHONPATH=. python -m src.main --source serial --port /dev/tty.usbserial-110
# Windows（PowerShell）
$env:PYTHONPATH="."
python -m src.main --source serial --port COM5
```

## 3. 应该看到

- 程序列出串口（macOS 为 `tty.usbserial-xxx` / `tty.wchusbserial-xxx`；Windows 为 `COMx`）；
- 屏幕底部每 0.25 秒刷新一行：

```
状态：有人　不动　短窗动作区 1.30e+08　帧 1234
```

- 人在面前动 → `有人` + `小动/大动`；
- 在房间里来回走动（包括转身那一刻）→ `有人` + `大动`，不会因为转身短暂停顿就掉成"不动"；
- 静坐（哪怕只是呼吸、偶尔动手指）→ `有人` + `不动`，不会丢失；
- 人离开 → 约 25 秒后变 `无人`。

> 为什么人离开后要等约 25 秒？
> 直接串口（不经过授权软件）时，静坐的人在雷达看来是"每隔几秒到二十几秒一次"的微弱信号。为了不把静坐的人误判成离开，程序要连续约 25 秒完全收不到人体信号才判无人。灯控本就有 5 分钟延时关灯，这个延迟不影响使用。

按 **Ctrl+C** 退出。

## 4. 用网页演示和记录（推荐）

不想看终端文字，可以让程序顺便起一个**本地网页**：浏览器打开就能看到大字状态、实时曲线和事件记录，电脑、手机都能看，不需要联网、不需要账号。

### 4.1 启动网页

在原来的命令上加 `--web` 即可（命令只决定最初数据源，进入页面后仍可切换实时/导入两种模式），三种初始数据都支持：

```bash
# 接真实雷达（实时）
PYTHONPATH=. python -m src.main --web --source serial

# 没带硬件，先看内置演示剧情（合成数据）
PYTHONPATH=. python -m src.main --web --source simulated --scenario demo

# 回放一个录制文件
PYTHONPATH=. python -m src.main --web --source replay --file /path/xxx.gz
```

（Windows PowerShell 同样把 `PYTHONPATH=.` 换成 `$env:PYTHONPATH="."`。）

### 4.2 打开页面

- 电脑：启动后看到提示网址，默认是 `http://localhost:8080`，直接在浏览器打开。
- 手机：手机和电脑连同一个 Wi-Fi，用电脑的**局域网 IP** 访问，例如 `http://192.168.1.23:8080`
  （macOS 在"系统设置 → Wi-Fi → 详细信息"里查 IP；Windows 在终端跑 `ipconfig` 查 IPv4 地址）。
- 端口被占用时，用 `--http-port 9000` 换一个，并把网址里的端口一起换掉。

### 4.3 页面能做什么

页面顶部可在两种模式间切换（不必重启程序）：

- **实时输入**：选择串口、点“连接并开始”接入真实雷达，即时反馈有人/动作/曲线；无硬件、扫不到串口会红字提示。
- **数据导入**：选择本地 `.gz` / `.dat` 录制文件，点“上传并分析”自动限速回放；整段播完显示“数据分析报告”（总帧数、时长、有人占比、不动/小动/大动分布、进出次数、最终状态）。

其余通用展示：

- **在场状态**：绿色"有人" / 灰色"无人"，旁边显示当前时间；
- **动作分级**：不动 / 小动 / 大动，用不同颜色标签；
- **实时能量曲线**：最近约 5 秒的距离门、动作门能量，有人时段有浅色背景；
- **事件记录**：自动记下每次进入、离开和动作变化的时间与帧号；
- **导出 CSV**：点"导出 CSV"保存全部记录（带中文表头，Excel 可直接打开）；
- **清空记录**：点"清空记录"清除当前列表。事件会存在 `web_data/events.json`，重启程序不丢。

## 5. 常见问题

**没找到串口 / 串口列表是空的**
检查 USB 转串口模组是否插好、是否需要装驱动（见 1.2）。

**数据是乱码、或读不到数据**
可能是波特率不对，依次尝试：

```bash
# macOS
PYTHONPATH=. python -m src.main --source serial --baud 921600
PYTHONPATH=. python -m src.main --source serial --baud 460800
PYTHONPATH=. python -m src.main --source serial --baud 230400
PYTHONPATH=. python -m src.main --source serial --baud 115200
```

（Windows PowerShell 把 `PYTHONPATH=.` 换成 `$env:PYTHONPATH="."`。）

**空房间却一直判"有人"**
检查雷达视野里有没有持续运动或振动的设备：饮水机（水泵/加热/风扇）、电风扇、空调、电脑或投影仪风扇、晃动的窗帘。程序已能自动过滤**近门电器的慢速振动**（它的反射只在近距离、传播不到远处距离门）；但电器**压缩机/水泵启动的瞬间**（0.3 秒、信号和人挥手一样强）仍会被当成动作。录制或演示前，最好把空调、饮水机关闭，或把它们移到雷达 6 米以外、挪到另一张桌子，再重新观察。

**开机时人已经坐着不动，没识别出来**
做一个挥手或起身动作即可；识别后静坐会一直保持，不需要持续动。如果人坐在雷达的侧面/较远的角度盲区，可能需要调整座位位置，让身体正对雷达。

**列出串口后，屏幕一直没刷新状态行**
说明串口连上了，但雷达没在发数据。检查雷达供电（红线 VCC）、接线是否接牢，或按 Ctrl+C 退出重连；程序每约 2 秒会打印一次"没收到数据"的提示。

**PowerShell 里出现红色文字，是报错吗？**
不一定。PowerShell 5.1 会把 pip 的升级提示、unittest 的进度（这些都写在 stderr）显示成红色，即使程序其实成功了。只要最后看到 `OK`、`Successfully installed` 或正常的状态行，就可以忽略这些红色文字。

**想看 Home Assistant 灯控界面**
需要先装 Docker，见 `deploy/README.md`。
