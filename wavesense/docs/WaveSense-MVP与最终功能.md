# WaveSense：MVP 与最终功能界定

> 配套《WaveSense-项目精简文档.md》与《WaveSense-最小功能实施流程.md》使用。
> 本文档回答一个问题：**2–3 周课程交付什么（MVP），完整产品最终长成什么（最终功能），两者如何衔接。**

---

## 1. 总览对照

| 维度 | **MVP（2–3 周必达）** | **最终功能（产品愿景）** |
|---|---|---|
| 场景 | 单房间（宿舍 / 演示房） | **单房间内多区域、多场景层次**（非多房间） |
| 感知 | 人在 / 离开检测（阈值 + 去抖，含静坐）；人数 0/1/2 | **区域级存在**：目标距离 / 角度 → 区域归属（门口 / 书桌 / 休息区）+ 行为状态（活动 / 静止）+ 区域转移；多人分区计数 |
| 联动 | 灯控：进入立即开、离开延时 5 min 关 | **区域差异化联动**：书桌区亮台灯、床区夜灯、门口判定进出；场景切换（进门 / 学习 / 休息 / 夜间起床） |
| 界面 | Home Assistant 本地仪表盘 | **房间平面示意图 + 目标实时位置 + 各区域状态面板**、趋势图表、告警推送（可选） |
| 数据 | 判定状态（presence 0/1）+ 进出日志，本地 SQLite | **区域事件日志**（何时在何区域）+ 长期作息洞察 + 原始信号训练 ML（可选） |
| 算法 | 规则判定（阈值 + 去抖） | 目标距离 / 角度 → 区域归属；区域状态判定（规则或 ML）＋多人目标关联 |
| 部署 | 单机：采集电脑 + 旧笔记本 Docker 跑 HA | **单雷达能力最大化**：同一块板卡 / 采集链路，升级判定与联动逻辑 |
| 验收 | 5 项指标（见 §4） | 产品级指标：误报率、**区域判定准确率**、场景切换鲁棒性、断网 / 断电自恢复 |

## 2. 演进路径：每一项 MVP 能力如何长成最终功能

| MVP 能力 | 最终功能形态 | 需要的增量 |
|---|---|---|
| 人在 / 离开（阈值判定） | **区域级存在**：目标落在哪个区域、活动还是静止 | 目标距离 / 角度 → 区域归属 + 状态判定 |
| 单房间单雷达 | **房间分区感知**：门口 / 书桌 / 休息区 Zone Map | 按距离门（~70.6 cm 分辨率）与角度划分区域 |
| 人数计数（0 / 1 / 2） | 多人分区计数（两人各在哪个区域） | 目标跟踪 + 区域关联 |
| 灯控自动化 | **区域差异化联动**：书桌区台灯、床区夜灯、门口判定进出 | HA 场景自动化（基于区域状态） |
| 本地仪表盘 | **房间平面图 + 实时目标位置 + 区域状态** | 位置数据可视化 |
| 进出日志 | **区域事件日志 + 作息洞察**（何时在何区域） | 区域级事件记录 + 长期数据积累 |

## 3. MVP 明确不做 → 最终版本归属

| 不做项（MVP） | 归属阶段 | 说明 |
|---|---|---|
| 从零训练 ML | 最终功能可选优先级 | 开发板数据可获得；区域规则判定够用时可不做 |
| 原生 App / 云远程 | 最终功能第二优先级 | 需网络部署与维护成本 |
| 家属推送告警 | 最终功能（可选） | 与区域异常检测配合 |
| **多房间扩展** | **明确不做** | 方向改为**单房间多层次**：最大化单个雷达的空间属性（距离 + 角度 + 区域划分） |
| 语音助手联动 | 最终功能（生态扩展） | 依赖 HA 集成成熟度 |

## 4. 验收差异

**MVP 验收（5 项指标，课程答辩）**：
空房 1 h 误报 = 0 ｜ 静坐 30 min 持续判定"有人" ｜ 双人判定计数 = 2 ｜ 灯控端到端 < 1 s ｜ 进出日志误差 < 2 s。

**最终功能验收（产品级）**：误报率 / 漏报率（如跌倒召回率 ≥ 95%）｜ 多房间一致性与切换鲁棒性 ｜ 断网 / 断电自恢复 ｜ 告警送达率与延迟 ｜ 长期数据洞察的可用性。

## 5. 阶段性路线建议

- **Phase 1（当前，2–3 周）＝ MVP**：单房间、规则判定、灯控 + 日志 + 仪表盘，按《最小功能实施流程》执行。
- **Phase 2（MVP 后）＝ 空间感知升级**：划分区域（Zone Map：门口 / 书桌 / 休息区）→ 目标区域归属判定 → 区域差异化联动（台灯 / 夜灯 / 主灯）。
- **Phase 3（长期）＝ 场景自动化与界面**：基于区域转移的场景切换（进门 → 学习 → 休息 → 夜间起床）+ 房间平面仪表盘 + 可选行为分类 ML。

> **单房间多层次的实现原理**：单雷达按距离门（~70.6 cm 分辨率）与角度把房间切成若干区域；目标位置 → 区域归属 → 区域状态（活动 / 静止）→ 触发该区域的联动与场景。层次 = 空间区域层 × 行为状态层 × 场景响应层。
