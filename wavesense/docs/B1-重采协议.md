# DEV202 重采协议（B1.5 / 上硬件照着做）

> 用途：第一批 6 个 DAT 样本在 "走动 vs 空房" 上分不开。
> 原因最大嫌疑是：采样条件不一致 + 没勾目标信息 / 2DFFT。
> 本页是上雷达电脑的操作清单，做完即可重新跑 
>
> `python analyze_samples.py`
>
>  出新版报告。



***

## 0. 出发前在本机确认



* [x] 雷达电脑上已装好授权软件 ONELAB（v1.5.4.1+），板子通过 CP210x 接到 COM5；

* [x] 尺子 / 卷尺、记录本（或手机备忘录），用来量安装高度、俯仰角、目标距离；

* [x] 项目目录准备好：新样本导出到 `samples/` 旁的临时目录，完事统一拷回本机 `samples/`，

  文件名继续用 `empty_01.dat / sit_01.dat / walk_01.dat` 这套前缀（脚本按前缀分组，不用改代码）。



***

## 1. 导出前必勾的选项（这次和上次最大的区别）

在授权软件的导出 / 参数设置里，确认以下勾选项：



| 项         | 要求                  | 说明                                              |
| --------- | ------------------- | ----------------------------------------------- |
| 目标信息      | ☑ 距离　☑ 角度　☑ 速度　☑ 状态 | 上次全没勾，people\_count 只能走 None 降级；这次勾上，脚本可直接用目标个数 |
| 2DFFT 速度谱 | ☑ 可导出               | 上次只导了 1DFFT，运动特征很可能在速度维；这次确认导出                  |
| 排除直流 bin0 | ☑ 勾选                | 与我们 config 里 `exclude_dc_bin0: true` 一致         |
| 距离缩放      | 1.0                 | 保持默认，不要动                                        |
| X 镜像      | □ 不勾                | 保持默认                                            |

> 导出时注意软件界面里显示的
>
> **配置文件路径**
>
> （形如 
>
> `C:\RadarData\...\FILE_Radar_Config.ini`
>
> ），
> 把这个 ini 一并拷回项目 
>
> `docs/`
>
> —— 它里面有真实的门定义 /chirp 参数，我们手里没有。



***

## 2. 安装条件：一次量好、全程不动

架好板子后，**所有场景共用同一套安装参数**，录完一段都不要挪板子。

量好后填到 `docs/DEV202-参数摸底记录表1.md` §3：



| 项                   | 记录位置   | 本次值     |
| ------------------- | ------ | ------- |
| 安装高度（离地面 / 床面）      | 记录表 §3 | 1.1m    |
| 俯仰角 / 朝向            | 记录表 §3 | 量好填     |
| 与被测目标（座椅 / 床）距离     | 记录表 §3 | 量好填     |
| 周围扰动源（风扇 / 窗帘 / 暖气） | 记录表 §3 | 确认关掉或记录 |



***

## 3. 三类场景采集协议（每类 ≥60 秒 × 2 段）



| 场景 | 动作要求                                  | 时长              | 文件名                           |
| -- | ------------------------------------- | --------------- | ----------------------------- |
| 空房 | 所有人离开房间，静置，环境安静，不要走动                  | ≥60 秒           | empty\_01.dat / empty\_02.dat |
| 静坐 | 人坐到固定座位上，保持安静少动（正常呼吸、偶尔小幅动），**位置不要换** | ≥60 秒，建议 ≥120 秒 | sit\_01.dat / sit\_02.dat     |
| 走动 | 在房间指定范围内以正常步速来回走，不跑、不停留，路径尽量覆盖雷达覆盖区   | ≥60 秒           | walk\_01.dat / walk\_02.dat   |

每段录完在记录本上记一行：



```
walk_01.dat  2026-10-2x  HH:MM  人距离板子 ~2m，正常步速来回
```



***

## 4. 录完回本机后



1. 新 DAT 拷到项目 `samples/`（覆盖前先把旧样本挪到 `samples/_old/` 留档，别直接删）；

2. 拷回的 `FILE_Radar_Config.ini` 放到 `docs/`；

3. 跑：



```
python analyze_samples.py
```



1. 重点看新报告：

* 走动 P50 是否 > 空房 P99（能分开就可以定 `energy_threshold`）；

* 静坐方差是否仍然最小（验证静坐路径）；

* 目标信息有没有解出来（`people_count` 不再是 None）。



***

## 5. 仍然分不开的预案

如果重采后走动和空房在 1DFFT 能量上还是分不开：



* 打开软件里的 Range-Doppler / 2DFFT 图，看人走动时速度维有没有亮线；

* 把软件界面截图（和 walk\_02 那张一样）发回来对拍；

* 考虑运动判定改走 "速度维能量" 或直接用软件给的目标信息，不再自己从 1DFFT 能量硬算。
