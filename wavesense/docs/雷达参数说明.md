# 雷达配置参数说明（DEV202H / ICL1122）

来源：授权软件导出的 `radar_config_A1_20261105.ini`（A1 空调开空房段录制时的配置）。
本文件只摘录与判定相关的参数，并标注与 Python 侧代码假设的核对结论。

## 1. 硬件与链路

| 参数 | 值 | 说明 / 核对 |
|---|---|---|
| ChipName | ICL1122 | BanyanET 系列 |
| ModuleName | DEV202H | 1T2R 开发板 |
| TxChannelBit | 1 | 1 发 ✓ 与项目两接收通道解析一致 |
| RxChannelBit | 3（二进制 11） | 2 收 ✓ |
| SourceType | radar_serial | 串口直连 |
| 串口波特率 | 921600 | ✓ 与项目默认波特率一致 |
| DriverType | data_transfer | 只传原始数据，板端不跑目标检测 |
| DataType | 1dfft | 输出 1DFFT 结果 |
| TxPoutdBm | 6.00 | 发射功率 |
| RxGaindB | 25.50, 25.50 | 两通道增益一致，无通道失衡 |

## 2. 波形

| 参数 | 值 | 说明 |
|---|---|---|
| WaveType | SAW_CW | 锯齿波连续波 |
| IdleFreq | 24.015 GHz | 起始频率 |
| TopFreq | 24.235 GHz | 截止频率，带宽约 220 MHz |
| ChirpsPerFrame | 64 | 板端一帧含 64 个 chirp |
| SamplesPerChirp | 8 | 每 chirp 采样 8 点 |
| FrameTimeUS | 129500 μs（129.5ms） | 板端帧周期，板端帧率约 7.72 fps |

### 帧率核对

板端一帧 129.5ms、含 64 chirp；项目解析的逻辑帧（ch0+ch1 各 18 个 int16）按 chirp 级输出估算：

- 逻辑帧率 ≈ 64 / 0.1295 ≈ **494 fps**
- 项目代码取 `FPS = 480`（`src/web/engine.py`），属保守近似，时长换算误差约 3%，不影响阈值标定。

## 3. 板端信号处理（关键）

| 参数 | 值 | 说明 |
|---|---|---|
| BGAccRemoveEnable | 0 | 背景累积去除 **关闭** |
| NoiseRemoveEnable | 0 | 噪声去除 **关闭** |
| BGClusterRemoveEnable | 0 | 背景簇去除 **关闭** |
| IIRType / IIRCoef | 1 / 4 | 板端 IIR 滤波 |
| HPFType | 300K | 高通滤波 |
| 1DFFT 窗 / 计算 | hamming / 256 点 | 输出 8 列 × 64 行 |
| 2DFFT 窗 / 计算 | hamming / 64 点 | 项目未使用 2DFFT |

**结论**：三个背景去除开关全部关闭，授权软件输出的是**原始 1DFFT 能量**，空房底噪里包含静止物体反射。
因此 Python 侧必须自己做基线与阈值判据，不能依赖固件静态对消。

### 帧布局对应

ini 里 1DFFT 输出 8 列距离门 × 64 行多普勒门；项目二进制帧每通道 18 个 int16，
布局（实测钉死，见 `src/data_source/frame.py`）：

- 位置 0–5：距离门（存在判定）
- 位置 6–15：动作/速度门（动作分级）
- 位置 16：参考字段；位置 17：常量

## 4. 授权软件自带检测（项目未使用，仅对照）

| 参数 | 值 | 说明 |
|---|---|---|
| RangeGateMin / Max | 5 / 7 | 软件侧关注的距离门范围 |
| ObjectMinEnergy | 25.0 | 软件目标能量阈值 |
| ObjectDetectType | RVA | 软件检测类型 |
| MTT_Threshold | 0.0200 | 软件跟踪阈值 |
| MTT_DisappearCount | 15 | 软件消失判定帧数 |

这些是授权软件内部算法参数，Python 判定链路不读取。

## 5. 后续采集注意事项

1. **保持配置一致**：每段录制尽量沿用同一套雷达配置，尤其是接收增益（RxGaindB）、
   背景去除开关、距离门范围；参数变了的样本不能和旧样本混在一起标定阈值。
2. **若要降低空房底噪**：可在授权软件打开 `BGAccRemoveEnable` 试录一段对比，
   但开/关两种数据要分开标注，且阈值需要重新标定。
3. 录制后在文件名旁备注：空调开/关、距离、角度、动作、时长。
