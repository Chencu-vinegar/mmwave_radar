# 新环境标定采样协议（WaveSense）

> 适用场景：雷达搬到新房间 / 改变安装位置 / 更换家具或电器布局后，需要在新环境重新标定阈值。
> 帧格式、波特率（921600）、距离门数（6 门）、判定结构与环境无关，**不需要改代码**；
> 需要重采样本并复核 `config/config.yaml` 里 `detector` 段的阈值。

## 0. 前置检查（雷达电脑上，只做一次）

1. 代码为仓库最新版：克隆或更新 `https://github.com/Chencu-vinegar/mmwave_radar.git`，代码在 `wavesense/` 下；
2. 依赖已装：
   ```powershell
   cd wavesense
   python -m pip install -r requirements.txt
   ```
3. 雷达接线正常（雷达 → USB 转 TTL 模组 → 电脑），授权软件能看到波形；
4. 把新环境的安装参数记入 `docs/DEV202-参数摸底记录表1.md`：安装高度、距墙距离、水平角度、朝向、房间大小、遮挡物。

## 1. 采样前环境控制

- 房间布置与**正式使用时一致**：家具位置、常开电器（空调、风扇、饮水机、投影仪）保持日常状态；
- 近门电器（雷达 1.5m 内的风扇/空调内机/水泵）尽量移到另一张桌子或 6m 以外；无法移动时在备注里写明位置；
- 采样期间不要开关门、不要换人、不要在雷达视野外走动后再进来；
- 每段录制的**开头和结尾各留 10 秒空场**（人离开），方便分析时剥掉进出过渡段。

## 2. 三类样本录制（授权软件导出 .gz）

| 场景 | 文件命名 | 建议时长 | 人员动作要求 |
|---|---|---|---|
| 空房 | `empty_01.gz`、`empty_02.gz` | ≥ 5 分钟/段 | 房间无人；电器保持日常工况（开着就录开着） |
| 静坐 | `rest_01.gz`、`rest_02.gz` | ≥ 5 分钟/段 | 人正对雷达坐 0.5–1.5m，看书或用电脑，偶尔手指微动；**不要起身** |
| 走动 | `walk_01.gz`、`walk_02.gz` | ≥ 3 分钟/段 | 房间内来回走动，包含转身、停步、再起步 |

- 导出格式用授权软件的 gzip 录制（`.gz`）；`.dat` 原始二进制也可以，分析脚本两者都读；
- 文件放到 `wavesense/samples/new_env/` 目录（目录不存在就新建）；
- 每段在备注里记：录制时间、人数、座位/走动位置、电器状态。

### 关于静坐样本（标定 `leave_gap_frames` 必须注意）

- 静坐的人体信号是**每隔几秒到二十几秒一次的稀疏尖峰**，尖峰之间和空房无法区分；
- `leave_gap_frames` 要从**未切分的整段静坐原始录制**上量尖峰间隔，**不能**用 `dataset/rest/` 里已经切好的短段（那些段只保留了尖峰附近，量不出最长间隔）。

## 3. 离线统计与阈值建议（开发机或雷达电脑均可）

样本拷回后，在 `wavesense/` 根目录运行标定脚本（脚本只读文件、不接串口、不改配置）：

```powershell
$env:PYTHONPATH="."
python tools\calibrate_thresholds.py `
  --empty samples\new_env\empty_01.gz samples\new_env\empty_02.gz `
  --rest  samples\new_env\rest_01.gz  samples\new_env\rest_02.gz `
  --walk  samples\new_env\walk_01.gz  samples\new_env\walk_02.gz
```

输出三类样本的短窗能量 / 动作区能量 / 远门比例分布，并给出建议值；报告同时存到 `tools/calibration_report.txt`。

### 复核建议值（对照脚本输出的分布表）

| config 参数 | 标定依据 | 复核要点 |
|---|---|---|
| `active_threshold` | 空房 P99 留余量 | 必须低于静坐距离门尖峰下沿，否则静坐判不出有人 |
| `far_gate_ratio` | 空房 P95 与静坐 P05 之间 | 空房误报先查近门电器，再抬高此值 |
| `small_move_threshold` | 静坐动作区 P95 留余量 | 静坐呼吸不应超过它（否则会被误判小动） |
| `large_move_threshold` | 走动动作区分布下沿 | 走动应稳定落在大动区间 |
| `leave_gap_frames` | 静坐最长尖峰间隔 ×1.2 | 静坐被误判离开就增大；离开关灯太慢则核对间隔后下调 |

确认无误后，人工把数值填进 `config/config.yaml` 的 `detector` 段（脚本不自动改写配置）。

## 4. 实机验收四项（雷达电脑，接串口运行）

```powershell
$env:PYTHONPATH="."
python -m src.main --web --source serial
```

1. **空房**：保持无人 ≥ 3 分钟，状态稳定“无人”，无误报；
2. **静坐**：人坐下后出现一个动作（挥手/起身再坐下），之后保持“有人 · 不动”，不丢；
3. **走动**：来回走动判“有人 · 大动”，转身停顿不掉成“不动”；
4. **离开**：人走出房间后，约 `leave_gap_frames` 对应时长（默认约 25 秒）内变“无人”。

任一项不达标：回到第 3 步对照分布表调对应参数，再复测。

## 5. 常见问题

- **空房一直判有人**：先查视野内是否有持续振动的电器/晃动窗帘；排除后再抬高 `active_threshold` 或 `far_gate_ratio`；
- **静坐识别不出来**：确认人正对雷达（侧面/远角是角度盲区），且 `active_threshold` 没有高过静坐尖峰；
- **走动转身瞬间掉状态**：检查 `walk_window / walk_strong_threshold / walk_strong_frames`（一般沿用旧值，新环境反射差异大时再复核）；
- **串口读不到数据**：确认波特率 921600、授权软件没有占用同一串口。
