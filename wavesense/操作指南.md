# WaveSense 操作指南

面向使用者的通俗手册。技术原理、阈值标定和已知限制见 `README.md`；
灯控部署细节见 `deploy/README.md`。

## 1. 这套东西能做什么

用 24GHz 毫米波雷达判断房间里有没有人、人是静坐还是在走动，把结果通过本地
MQTT 发给 Home Assistant，再控制智能灯泡亮灭。全程在局域网运行，不连云、
不训练模型、不用手机 App 做判断。

检测结果分三档动作：**不动**（静坐呼吸）、**小动**（抬手、转头、打字）、
**大动**（挥手、起身、走动）。

## 2. 准备环境

### 2.1 电脑环境

- Python 3（官网 python.org 下载安装包，安装时勾选加入 PATH）。
- 进入工程目录后安装依赖：

```bash
cd wavesense
pip install -r requirements.txt
```

> 工程里自带 `.venv` 虚拟环境时，优先用 `.venv/bin/python`（macOS/Linux）
> 或 `.venv\Scripts\python`（Windows）；没有虚拟环境就用 `python3`。

### 2.2 硬件接线

DEV202 雷达小板用 4 根杜邦线接 USB 转 TTL 串口模组，再把模组插电脑 USB：

| 雷达线 | 接串口模组 |
|---|---|
| 红 VCC | VCC |
| 黑 GND | GND |
| 白/黄 TXD | RXD |
| 白/黄 RXD | TXD |

接线图见 `docs/硬件连接方式.jpg`。串口默认波特率 921600。

## 3. 最快启动

### macOS / Linux

双击 `启动网页.command`；或在终端运行：

```bash
PYTHONPATH=. .venv/bin/python -m src.main --web
```

### Windows

双击 `启动网页.bat`；或在终端运行：

```bash
set PYTHONPATH=.
.venv\Scripts\python -m src.main --web
```

启动后浏览器自动打开 `http://localhost:8080`。没接雷达时，程序自动跑
内置演示场景，方便先看界面。

## 4. 三种数据来源

程序支持三种输入，用 `--source` 切换：

| 来源 | 命令 | 用途 |
|---|---|---|
| 演示合成 | `python -m src.main --source simulated --scenario demo` | 不接雷达，看界面和判定流程 |
| 文件回放 | `python -m src.main --source replay --file 路径/xxx.gz` | 回放之前录好的 `.gz` / `.dat` |
| 实时串口 | `python -m src.main --source serial --port /dev/tty.usbserial-xxx` | 接雷达实时检测 |

- 不带 `--port` 时，串口模式会自动列出可用串口并选第一个。
- 回放/实时模式都可以加 `--web` 打开网页，加 `--mqtt` 把结果发出去。
- 网页里也能上传 `.gz` / `.dat` 文件直接回放分析，不用敲命令。

## 5. 网页怎么看

打开 `http://localhost:8080`，页面分几块：

| 区域 | 看什么 |
|---|---|
| 状态卡片 | 当前有没有人、动作档位（不动/小动/大动） |
| 能量曲线 | 距离门、动作区、远门比例随时间的走势 |
| 事件记录 | 每次进入/离开/分级变化的历史，可清空、可导出 CSV |
| 判定依据 | 当前距离门、动作门、远门比例、长窗抬升、基线状态 |
| 学习空房基线 | 房间无人时点一次，采集约 30 秒空房底噪，固化后保存到 `web_data/baseline.json`，重启自动复用 |

- 导出的 CSV 带 BOM，Excel 直接打开不乱码。
- 上传文件回放后，页面会给出整段分析报告（有人占比、分级占比、最长漏检段）。

### 学习空房基线怎么做

1. 确认房间里没人、空调/风扇/饮水机等强干扰源按实际使用状态开着。
2. 网页点「学习空房基线」，保持无人约 30 秒。
3. 采集满后基线自动固化；之后活动判据会在绝对阈值之上，再叠加一条
   "相对基线抬升"条件，压制本房间的持续高底噪。
4. 基线没学完时，相对条件自动不生效，保持原有行为。

## 6. 接雷达实时检测

1. 雷达按第 2.2 节接好，插电脑 USB。
2. 先列出可用串口：

```bash
PYTHONPATH=. .venv/bin/python -m src.main --source serial
```

不带 `--port` 时终端会打印检测到的串口设备名。
3. 用对应串口启动：

```bash
PYTHONPATH=. .venv/bin/python -m src.main --source serial --port /dev/tty.usbserial-xxx --web
```

4. 人走进波束看状态卡片是否变有人；静坐看是否保持有人；走出后等约 25 秒
   判据窗口，看是否翻回无人。

> 离开判据需要连续约 25 秒无活动尖峰才判无人，刚走出不会立刻翻无人，属正常。

## 7. 接灯泡联动（概览）

完整步骤见 `deploy/README.md`，链路是：

```
雷达 → Python 程序 → 本地 Mosquitto → Home Assistant → WiZ 灯泡
```

1. 起本地服务：`cd deploy && docker compose up -d`，HA 在 `http://localhost:8123`。
2. 手机 WiZ App 把灯泡连上 2.4GHz WiFi，打开"允许本地通信"。
3. HA 添加 WiZ 集成，记下灯泡实体编号（形如 `light.wiz_bulb_xxxx`）。
4. 把 `deploy/homeassistant/config/configuration.yaml` 里两处 `light.placeholder_light`
   换成真实灯泡编号，重启 HA。
5. 不接雷达先验证：

```bash
docker exec wavesense-mosquitto mosquitto_pub -t wavesense/room1/presence -m "1"
docker exec wavesense-mosquitto mosquitto_pub -t wavesense/room1/presence -m "0"
```

6. 雷达程序加 `--mqtt` 启动，结果就会自动推给 HA。

关灯延时在 `config/config.yaml` 的 `light_off_delay_sec`，默认 300 秒。

## 8. 录数据与跑回归

### 8.1 录制注意

- 稳态段保持姿势，不要来回换动作；动作段幅度稳定，方便分级标定。
- 开头结尾各留 5–10 秒连接/断开缓冲，分析时剔除。
- 同一条件重复录几段，尖峰是稀疏随机的，单段容易偏。
- 录负样本时房间必须确实无人。

### 8.2 标注

样本场景标注在 `tools/regression_labels.json`，每条记 `scene`
（empty/rest/small/large/walk）和 `note`（距离、角度、空调、动作等条件）。

### 8.3 跑批量回归

```bash
# 全部样本 + dataset 纯段
PYTHONPATH=. .venv/bin/python tools/regression.py

# 只看指定场景
PYTHONPATH=. .venv/bin/python tools/regression.py rest walk
```

输出各段有人占比、进入/离开次数、分级占比、最长连续有人/无人段。

### 8.4 跑单元测试

```bash
PYTHONPATH=. .venv/bin/python -m unittest discover -s tests
```

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| 找不到 Python | 先装 Python 3 并加入 PATH，重开终端 |
| 串口找不到 | 检查接线、USB 模组驱动；不带 `--port` 先列串口 |
| 空房一直误报有人 | 先在网页学习空房基线；确认空调/风扇/饮水机状态；录制基线时尽量关闭强干扰源 |
| 人静坐长时间被判无人 | 多为远距离弱反射或角度盲区，见 README 已知限制；调整雷达朝向对准人常待位置 |
| 走出后很久不判无人 | 离开判据有约 25 秒空档；若一直不离开，多为环境底噪偏高，需学习基线后复核 |
| HA 搜不到灯泡 | 确认电脑和灯泡同一 WiFi、2.4G 正常；搜不到就手动填灯泡局域网 IP |
| 发了消息灯没反应 | 核对配置里灯泡实体编号、灯泡通电、本地通信已打开 |

## 10. 配置文件速查

阈值和窗口都在 `config/config.yaml`，常用项：

| 配置项 | 含义 | 默认 |
|---|---|---|
| `active_threshold` | 距离门活动绝对阈值 | 1.8e9 |
| `enter_frames` | 连续超阈值多少帧判进入 | 10 |
| `leave_gap_frames` | 连续无活动多少帧判离开 | 12000（约 25s） |
| `far_gate_ratio` | 远门能量占比过滤线 | 0.08 |
| `small_move_threshold` | 小动/不动分界 | 4.0e8 |
| `large_move_threshold` | 大动/小动分界 | 2.6e9 |
| `baseline.ratio` | 相对基线抬升倍数 | 1.8 |
| `light_off_delay_sec` | 无人后关灯延时（秒） | 300 |
| `mqtt.host/port/topic` | 本地 broker 地址与主题 | localhost:1883 / wavesense/room1 |
