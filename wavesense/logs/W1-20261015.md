# WaveSense 学习日志 · 第 1 周

**周期：2026-10-15 ~ 2026-10-19**

## 本周完成

- 确定项目方向：矽典微 DEV202（24GHz 毫米波雷达）单房间人体存在检测
- 完成 Proposal 和 PRD 文档，明确 MVP 范围：不做云、不做 ML、不做原生 App
- 搭好 Python 项目骨架，配置依赖（pyserial、paho-mqtt、numpy、pyyaml）
- 写通雷达数据帧解析：1 帧 = ch0+ch1 成对各 18 个 int16，采样率 480fps
- 实现数据读取抽象层：FileReplaySource（读 .gz 录制）和 SimulatedSource（合成模拟数据）
- 写第一版存在判定器：短窗能量阈值 + 连续帧去抖，区分有人/无人
- 搭好 MQTT 发布模块和 Home Assistant + Mosquitto 的 Docker 配置清单
- 用合成数据跑通离线链路：读帧 → 判定 → 发 MQTT → HA 收到

## 学到的东西

- 毫米波雷达不用摄像头，靠发射电磁波的回波多普勒检测微动，隐私性好
- DEV202 板内已经做了 DSP/滤波/CFAR，我们只需要在 Python 侧做规则判定
- 所有阈值先放 config.yaml 配置文件里，不硬编码，后面实测再调
- 先离线后实时：拿到硬件前先用模拟数据把链路写通，硬件到了只换数据源

## 遇到的问题

- 帧格式一开始没对齐，ch0/ch1 顺序和 int16 解析踩了坑，打印原始字节才搞清楚
- 模拟数据要足够真实才能验证判定器，后面补了空房/静坐/走动三种场景
