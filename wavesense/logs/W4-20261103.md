## 学到的东西

- 软件要"傻瓜化"：双击就能跑，不用别人看 README 敲命令
- 没硬件时自动降级演示数据，演示现场才不会翻车
- 跨平台中文文件名 zip 要设 UTF-8 标志位（0x800），不然 Windows 解压乱码
- GitHub 推送用 Personal Access Token，不用密码；token 要勾 repo 权限

## 遇到的问题

- auto 模式要过滤系统调试口（debug-console、bluetooth），不然会误选
- 自动开浏览器要用 threading.Timer 延迟 1.5 秒，等服务起来再开
- GitHub push 没有 SSH key，HTTPS 又没配凭据，最后用浏览器生成 token 嵌入 URL 推上去
