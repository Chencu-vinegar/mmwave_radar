# mmwave_radar

毫米波雷达相关工具的集合仓库。

## 子项目

| 目录 | 说明 | 状态 |
|------|------|------|
| [radar_viewer](./radar_viewer) | DEV202H（ICL1122）毫米波雷达数据读取与收集软件 | 初版 v0.1 |

## 说明

- 各子项目的安装、使用、构建方式请参见其目录下的 `README.md`。
- 本仓库为个人学习与验证用途，代码按现状提供。

1、项目初期，为了连上雷达，我们请教了老师和学长，下载了官方驱动程序并完成正确的雷达接线，利用官方提供的界面了解到雷达的基本原理和数据处理的途径

2、我们划定分工，每个人都开始利用ai设计程序，试图对雷达的数据进行处理然后价格，最后选择最优版本

3、我们确定了后端的东西，连接一个灯泡，利用雷达实现对有无人的判断，然后实时控制灯泡开关
